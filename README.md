# Buzzkill
Instagram Comment Moderation Demo

An Instagram-style web prototype designed to intercept toxic comments and modern insulting slang before they go live. Flags flagged comments and routes them to a pending queue for the Original Poster (OP) to approve or reject.

Features

Commenter View: Type and submit comments on a post. Flagged comments are intercepted immediately without posting publicly.

Original Poster (OP) View: Review held comments and choose whether to approve or reject them.

Custom Slang & Keyword Interceptor: Filters hate speech and derogatory slang words/phrases.

Tech Stack

HTML5

CSS3 (Mobile-first responsive styling)

Vanilla JavaScript (Split into Data, Rules, Display, and Start modules)
